# new/ — open and planning

A ticket starts here: written **before** the work, self-sufficient for an agent
with a clean context ([`../../rules/tickets.md`](../../rules/tickets.md)). It
leaves only when the definition of done in [`../AGENTS.md`](../AGENTS.md) is met —
merged to `main`, pushed, ticket moved to `done/`, README row updated. Work that
is merely unfinished stays here (a branch is not a landing).
